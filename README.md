# MilPrep — Sổ Tay Tân Binh TQSQK7

Ứng dụng web mobile-first dạng slide, giúp sinh viên chuẩn bị tham gia học Giáo dục Quốc phòng & An ninh (GDQP&AN) tại Trường Quân sự Quân khu 7 (TQSQK7): vị trí tập trung, dự toán chi phí, checklist đóng gói, hành trang khuyến nghị, đồ vật bị cấm, và bí kíp sinh tồn.

## Chạy dự án

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech stack

React + Vite + TypeScript, Tailwind CSS, lucide-react, canvas-confetti.
